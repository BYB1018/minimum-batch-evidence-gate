# Minimum-Batch Evidence Gate

## 中文

为新方向设计足够小、但能触达下一层真实信号的实验批次，并预先绑定扩大、修改或停止的证据门。

适用于求职、内容、GEO、虚拟产品等首轮实验；不是随意少做一点。开始前明确样本、时间窗、主要变量、决策阈值和最大损失。

## English

Design a small experiment that can reach the next meaningful signal, with evidence gates defined in advance for scaling, changing, or stopping.

Use it for first experiments in job search, content, GEO, digital products, and similar areas. “Small” must still be decision-useful. Define sample size, time window, primary variable, thresholds, and maximum loss first.
